Informativa privacy

Bozza operativa da completare. Questa pagina descrive le funzioni tecniche attualmente presenti nel sito. Prima di considerarla un'informativa definitiva, il gestore deve inserire i propri dati identificativi e un contatto valido, verificare le condizioni dei fornitori esterni e completare ogni eventuale adempimento applicabile.

Questi dati non sono stati inventati e devono essere completati dal gestore. GitHub Pages è il servizio di hosting del sito e non viene indicato come titolare del progetto.

2. Dati inseriti e archiviati sul dispositivo

Le funzioni facoltative di analisi consentono di importare file di movimenti e di creare budget, preferiti e snapshot. Il codice del sito conserva questi elementi nel local storage del browser sul dispositivo utilizzato. I dati importati, i budget, gli snapshot e i preferiti restano disponibili nello stesso browser finché non vengono cancellati dall'utente o rimossi tramite la pulizia dei dati del sito.

La web app installabile usa inoltre la Cache Storage del browser tramite un service worker per conservare le pagine statiche e una copia della cache pubblica CoinMarketCap, così da consentire la consultazione offline. Questi elementi memorizzati sono contenuti pubblici del sito, non i file personali importati.

Il sito non richiede password bancarie, credenziali degli exchange, seed phrase o chiavi private. Non inserire queste informazioni. L'analisi dei movimenti importati viene eseguita localmente nel browser; non caricare i file personali su servizi esterni tramite il sito.

3. Dati tecnici e servizi esterni

Per mostrare dati pubblici il browser può effettuare richieste a servizi di terze parti, tra cui Binance, Coinbase, OKX, Kraken, CoinGecko e GitHub. Il sito legge da GitHub anche i file dell'archivio pubblico dei prezzi. I dati CoinMarketCap vengono raccolti da un processo automatico GitHub Actions e salvati nel repository pubblico per essere poi letti dal sito.

Quando il browser contatta questi servizi, i rispettivi fornitori possono ricevere dati tecnici della connessione, come indirizzo IP, informazioni sul browser, data e ora della richiesta, secondo le proprie informative e condizioni. I link agli explorer esterni vengono aperti soltanto quando l'utente li seleziona.

Il sito è pubblicato tramite GitHub Pages. GitHub può trattare dati tecnici relativi alla richiesta e alla sicurezza del servizio secondo la propria documentazione privacy. I fornitori esterni operano come soggetti indipendenti secondo i rispettivi ruoli e termini; il gestore deve verificarne l'inquadramento per il proprio caso concreto.

4. Cookie, pubblicità e strumenti di analisi

Al momento gli script Google AdSense e Google Analytics non vengono caricati dalle pagine del sito. L'integrazione pubblicitaria è stata sospesa in attesa del completamento dell'informativa e della configurazione del sistema di gestione del consenso eventualmente necessario. Non è quindi corretto considerare attiva la visualizzazione di annunci sulla base del solo file ads.txt presente nel repository.

Il sito utilizza il local storage del browser per le funzioni descritte sopra. I servizi di hosting e le API esterne possono applicare proprie tecnologie o registrazioni tecniche, disciplinate dalle rispettive informative. Prima di attivare pubblicità, analytics o altri strumenti non strettamente necessari, il gestore deve aggiornare questa pagina e verificare gli obblighi di informazione e consenso applicabili.

5. Conservazione e cancellazione

I dati salvati nel local storage restano sul dispositivo fino alla cancellazione manuale, alla rimozione dei dati del sito dal browser o alla disinstallazione/azzeramento del profilo browser. Alcuni snapshot sono limitati dal codice agli ultimi 30 elementi. I dati pubblici di mercato sono conservati nel repository secondo la cronologia e le politiche di GitHub; non sono dati personali importati dagli utenti.

6. Diritti dell'interessato

Quando il gestore tratta dati personali in qualità di titolare, l'interessato può esercitare i diritti previsti dalla normativa applicabile, inclusi accesso, rettifica, cancellazione, limitazione, opposizione e, nei casi previsti, portabilità e reclamo all'autorità di controllo. Per esercitare tali diritti occorre usare il contatto privacy indicato dal titolare: il campo è ancora da completare.

7. Sicurezza e aggiornamenti

Non condividere dati di autenticazione, chiavi private o informazioni finanziarie non necessarie. Mantieni aggiornato il browser e usa un dispositivo protetto. Questa informativa deve essere aggiornata quando cambiano le funzioni, i fornitori, le finalità o gli strumenti di tracciamento del sito.
